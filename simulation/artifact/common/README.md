# Shared Artifact Files

These files support `artifact/run_artifact.sh` and are not normally invoked
directly.

- `experiments_extended.csv`: reference list for managed experiment entries.
- `run_paper_matrix.py`: matrix inspection utility.
- `run_status.py`: run and task status maintenance.

Use the top-level [artifact README](../README.md) for run, parse, plot, and
status commands.
